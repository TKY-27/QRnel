SeaBIOS 1.16.2

SeaBIOS and SeaVGABIOS run as firmware in the virtual machine. GNU LGPL v3, GNU GPL v3, corresponding source archive and build configuration.

To rebuild the release firmware, extract the source archive, copy seabios.config to .config in the source directory and run make there. The outputs are out/bios.bin and out/vgabios.bin. The upstream build script records the release and debug variants.
